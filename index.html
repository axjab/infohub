Fix · GPS-inspired architecture

Observe → publish → derive → materialize → read

Reading is never collecting.

Collectors run on schedules or events; resolvers compute values and atomically update cached files. A prompt only reads the cache. Returned scalars carry no formatting; units, timestamps and freshness live in metadata.

Deployment detail.

“Satellite” means a collector node, not necessarily a remote computer. /run/info is an illustrative runtime path (cleared after reboot); choose persistent storage separately for retained history. AI is asynchronous.
